DMS v2 - cara pasang
====================

Zip ini sudah mencakup semua update sebelumnya, jadi cukup pasang yang ini.

0. BACKUP DATABASE DULU (HeidiSQL/Laragon: klik kanan database > Export),
   terutama bila v2.24 belum pernah dipasang: kolom email akun diganti
   nama pengguna.
1. Salin semua isi zip ini ke folder dms-laravel Anda, pilih "Replace / Ganti" bila ditanya.
2. Di Git Bash (atau terminal Laragon), dari folder dms-laravel jalankan:

     php artisan migrate
     php artisan optimize:clear

   PENTING: langkah "php artisan migrate" wajib. Error
   "Unknown column 'kendaraan.aktif_sejak'" muncul karena langkah ini
   belum dijalankan. Sekarang, bila lupa, aplikasi akan menampilkan
   halaman petunjuk, bukan error SQL.

3. Buka lagi aplikasinya dan tekan Ctrl+F5 supaya tampilan baru termuat.

SINKRON DATA DMS LAMA (setiap kali DMS lama terupdate)
  Langsung dari file export, TANPA impor ke server:
  1. Export database DMS lama di phpMyAdmin seperti biasa (file .sql,
     mis. tersimpan di Downloads sebagai "db_dashboard (new).sql").
  2. Di Git Bash:
       cd /d/dms-laravel
       php artisan dms:sinkron
     Otomatis memakai file db_dashboard*.sql TERBARU di folder Downloads,
     lalu tanya "Sinkron data dari file ini?" -> tekan Enter.
     File di tempat lain:  php artisan dms:sinkron "D:\folder\nama file.sql"
  3. Selesai (sekitar 30 detik). Muncul ringkasan jumlah data.
  Aman diulang kapan saja: data yang sama diperbarui (tidak dobel), data
  baru ditambahkan, akun yang sudah ada di DMS v2 tidak diubah. File .sql
  hanya dibaca, tidak diubah.

  Alternatif (bila database DMS lama sudah ada di server yang sama):
  jalankan query database/sql/sinkron_dms_lama.sql di phpMyAdmin.
